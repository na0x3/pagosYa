Descarga la plantilla, complétala en Excel o Google Sheets y guarda una fila por producto.

Ver columnas y ejemplos

Para empezar solo necesitas nombre y precio. Si el producto tiene tamaños u opciones, deja el precio vacío y usa la columna opciones. Las demás columnas pueden quedar vacías.

Emitir una llave secreta de producción no se hace desde esta página: una sesión del panel comprometida nunca debe poder generar una credencial permanente y de máximo alcance. Una vez aprobado el KYC, llama a POST /v1/merchants/live_keys — hermana de POST /v1/dashboard/signup — desde tu propio backend, autenticado con tu llave secreta actual.
