# Great e-commerce generator (owner 2026-11-15 «lets do all of these» + «fuller homogeneous stores like brightland.co/products/the-holiday-feast-set»)

One plan, in this order. Each step ends with a measured result before the next starts.

1. **Full, homogeneous product page (Brightland bar).** The product call writes a long product page in the store's design system:
   rich buy area (gallery mosaic, rating, includes/highlights, add, guarantee, pairs, accordions), then brand chapters (uses with
   photos, story/origin band, trust row, real reviews, related products). Brightland PDP frames shown as the bar. New check: product
   page length + brand consistency (same fonts/colours as the home).
2. **Cost.** Each parallel call gets only what it needs (tokens + class list instead of the whole sheet; no Shell code for halves);
   measure characters sent per store before/after.
3. **Measured quality bar.** `scorecard` script: runs the page checks on the latest design of the benchmark stores, with time and
   cost from rounds.jsonl → one artifact page; approved stores kept as examples (first: Gramiyaa V2 r3).
4. **The whole store branded.** Catalogue/collection page, then checkout, in the store's design system.
5. **V2 in the real YAPI chat.** First design by V2 (composer stays as the quick option), gated by plan/credits, failure messages,
   publish like template stores.
6. **Editing by section.** «Change this section» / click a section → the section-fix path rewrites only it, with undo.
7. **Photos.** Background removal for floating products, crops, colour consistency; copy in the merchant's tone.

Live tests run on the ChatGPT plan: Gramiyaa (oil — the Brightland match), animated Oh Belly, NOA, Meat House.
