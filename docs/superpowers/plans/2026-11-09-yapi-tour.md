# YAPI store tour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, owner «hazlo desde ya»). Checkbox steps; TDD per task.

**Goal:** YAPI walks the merchant through the store section by section (likes / changes / skips), changing a section on request.
**Spec:** `docs/superpowers/specs/2026-11-09-yapi-tour-design.md` (approved: «hazlo desde ya escribe el plan y construyelo»).
**Facts:** home sections = `readMasterState(files).layout` (source-templates.ts:192, blocks `{ type, title?, … }`); chat messages are
`StoreAgentMessage { threadId, channel: 'source', role, content, metadata }`; a chat request may carry
`selection: { area: { sections: [{ page, at }] } }` (source-point-focus.ts) so the quick edit focuses one section; first-build hook in
`source-chat-jobs.service.ts` (`isFirstBuildStep` → popup look). Popup look name: `POPUP_LOOK_NAMES[pickPopupLook(slug)]`.

## Tasks
1. **`source-tour.ts` (pure)** — `tourSteps({ layout, hasProduct, popupLookName })` → steps `{ id, kind, page, at?, part?, label }`:
   header, home blocks in order (label = block.title || a Spanish name for its type || `Sección n`), footer, product (when any), popup
   («Tu ventana de suscripción — estilo X»), cart. `stepLine(step)` → the YAPI line + «¿Te gusta así o cambio algo?». `TOUR_REQUEST`
   regex («muéstrame mi tienda», «hazme un tour», «recorre(r) mi tienda»). Spec `source-tour.spec.ts`.
2. **`SourceTourService`** (storefront-source) — `offer(storeId)` (once; stores ≤ 3 days; message «¿Te muestro tu tienda sección por
   sección?» metadata `tour: { id, offered: true }` + chips Empezar/Ahora no); `start(storeId)` (resume open tour else build steps, post
   step 0); `answer(storeId, tourId, action)` like/skip → next; change → «¿Qué le cambio? …» with `tour.waiting = stepId`;
   ok/again after an edit; at the end the summary «Te gustaron N secciones, cambiamos M» (+ disliked note). State on the newest tour
   message metadata `tour: { id, steps, at, liked, changed, disliked, waiting?, done? }`. Spec `source-tour.service.spec.ts` (prisma mock).
3. **Wiring** — jobs hook calls `tour.offer` after the popup look; chat send: a message matching `TOUR_REQUEST` → `start`; a message
   while `tour.waiting` → normal quick edit with `selection` for that step, then `afterEdit` posts «¿Así está bien?» (Sí, sigue /
   Cámbiala otra vez); controller `POST /stores/:id/source-project/tour/start` and `/tour/answer { tourId, action }`.
4. **Studio** — on `metadata.tourStep`: scroll preview to the section (home index / header / footer), product → open first product,
   popup → «Ver ventana», cart → open cart; outline 2px accent 3 s (reduced motion: still). Chips post the answer. «Recorrer mi tienda»
   button in the YAPI panel. Test in the Studio suite; `tsc`; `vite build --mode embedded`.
5. **Live** — a test store: start via chat «muéstrame mi tienda», walk steps, change one section, summary; screenshots.
