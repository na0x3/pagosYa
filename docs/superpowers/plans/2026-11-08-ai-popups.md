# AI-designed popups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every new store gets a signup popup that YAPI designs for it (its own HTML + CSS around fixed platform slots, always with a
photo, on desktop and phones), the merchant can redesign / change its photo / undo from the chat and preview it in the Studio, and the
built-in popup stops hiding its photo on phones.

**Architecture:** A *popup kit* (`{ html, css, photo, seed, createdAt, model }`) is stored in `StoreRetention.settings.popupKit`
(JSON, no migration) by a new `PopupKitService` in `apps/api/src/store-popups/`, modelled on `EmailKitService`. The kit is written by
one model call, checked by a parse5/postcss validator and by a Playwright render of the real `retention.js`, and repaired once before
falling back. `retention.js` fills the slots on the store page; a store without a kit keeps today's layout.

**Tech Stack:** NestJS + Prisma (apps/api), parse5 7.3.0, postcss 8.5.25, playwright 1.62.1 (all already in apps/api), plain JS kit
(`packages/storefront-kit/kit/retention.js`), Vite Studio (`apps/merchant-studio`), jest.

**Spec:** `docs/superpowers/specs/2026-11-08-ai-popups-design.md`

## Global Constraints

- Storage: `StoreRetention.settings.popupKit`, `settings.popupKitPrevious` (one step of undo), `settings.popupKitTriedAt` (first-build
  attempt marker). No migration. The welcome code itself stays private.
- Slots: `<pya-photo>`, `<pya-title>`, `<pya-text>`, `<pya-form>` exactly once each; `<pya-code>` at most once. The close button is
  always the platform's, top-right, outside the AI's HTML.
- HTML ≤ 12 KB; CSS ≤ 16 KB; words outside the slots ≤ 80 characters, no prices, numbers, dates, percentages or offers.
- CSS: every selector under `[data-popup-kit]`; banned `position:fixed|sticky`, `url(`, `@import` (any at-rule other than `@media`,
  `@keyframes`, `@supports`), `expression(`, `behavior`, `-moz-binding`, `content` over 20 characters, `z-index` above 10,
  `display:none` / `visibility:hidden` / `opacity:0` on a slot. Keyframe names start with `pk-`. Reduced motion turns animations off.
- Render check at 1280×800 and 390×844: close, title and email field visible and inside the viewport; consent and submit visible and
  inside it horizontally; photo visible and ≥ 120px tall; title and email label contrast ≥ 4.5:1 on a flat opaque background, never
  laid over the photo; no horizontal overflow.
- Model `EMAIL_KIT_MODEL` (`gpt-5.6-terra`), usage stage `popup-kit`, through `sourceProvider` (unmetered on the ChatGPT plan).
  At most 12 credits per call (`POPUP_KIT_MAX_CREDITS`); `PlansService.assertCredits` before each design.
- One repair call after a failed validation or render check; failing again, nothing is saved.
- Merchant copy (Spanish): «Diseñé tu ventana de suscripción. Mírala en Mi tienda › Marketing con «Ver ventana de suscripción».»,
  «estoy diseñando tu ventana de suscripción nueva; aparece en un minuto», «No pude diseñar una ventana nueva esta vez; dejé la que tenías.»
- Existing stores are untouched until redesigned or named in the batch script.
- Dev rules (owner): one spec file per jest run, no full `tsc`, no multi-suite runs; edit files with the Edit tool (never `sed -i`:
  the API watcher stops compiling such files); saving `apps/api` restarts `nest --watch` and interrupts any running YAPI job; start
  the stack with `pnpm dev:chatgpt`; never run `prisma migrate` (none is needed). Commit only when the owner asks for commits — the
  «Checkpoint» steps below list what would go in each commit.

## Review Focus

1. **Ajustes saves after a design.** The Studio form posts only its own fields; `RetentionService.save` rebuilds `settings` from the
   DTO, so a saved popup design would vanish on the next «Guardar configuración». Expected: the design, its previous and the attempt
   marker survive. Test in Task 5.
2. **Published (hosted) stores.** There `secureFields` removes the email, name, phone and consent fields from `<pya-form>` (they are
   typed in pagosYa's secure form). Expected: the kit still shows its submit button and photo. Test in Task 3.
3. **A kit photo that no longer loads** (deleted upload, 404). Expected: the popup still opens with its form; the photo slot shows the
   monogram. Test in Task 3.
4. **A kit the page cannot use** (a slot missing — an old or tampered row). Expected: the built-in layout, never a broken popup. Test
   in Task 3.
5. **A store with no photo at all.** Expected: no design is attempted (the popup cannot have its picture), the built-in popup stays,
   and a merchant-asked redesign answers «No pude diseñar…». Test in Task 7.

/// <reference lib="dom" />
/** The signup popup as shoppers get it (spec 2026-11-08 AI popups): the real retention.js in demo mode (never sends), in an offline
 *  Chromium whose only answered request is the popup photo, measured at desktop and phone width. */
import { chromium } from 'playwright';
import { readKitFileSync } from '@pagosya/storefront-kit';

export type PopupLook = { background?: string; foreground?: string; accent?: string; accentForeground?: string; radius?: string };
export type PopupBox = { x: number; y: number; width: number; height: number; visible: boolean };
export type PopupPart = 'dialog' | 'close' | 'photo' | 'title' | 'email' | 'consent' | 'submit';
export type PopupMeasure = { width: number; height: number; dialogOpen: boolean; scrollWidth: number; boxes: Record<PopupPart, PopupBox | null>;
  contrast: { title: number | null; emailLabel: number | null }; titleOverPhoto: boolean };
export type PopupRenderInput = { storeName: string; settings: Record<string, unknown>; look: PopupLook; photo?: { bytes: Buffer; contentType: string }; hosted?: boolean };

export const POPUP_PHOTO_URL = 'https://popup-check.invalid/photo';
export const POPUP_SIZES = [{ width: 1280, height: 800 }, { width: 390, height: 844 }] as const;
const HEX = /^#[\da-f]{6}$/i;

function pageHtml(input: PopupRenderInput) {
  const look = input.look;
  const tokens = [['--store-background', look.background], ['--store-foreground', look.foreground], ['--store-accent', look.accent],
    ['--store-accent-foreground', look.accentForeground]].filter(([, value]) => value && HEX.test(value)).map(([name, value]) => `${name}:${value}`);
  if (look.radius && /^\d{1,2}px$/.test(look.radius)) tokens.push(`--store-radius:${look.radius}`);
  const retention = { ...input.settings, signupEnabled: true, popupTrigger: 'load',
    signupVisual: { brand: { name: input.storeName }, imageUrl: input.photo ? POPUP_PHOTO_URL : null, interests: [] } };
  const config = { slug: 'popup-check', demo: true, apiBaseUrl: 'https://popup-check.invalid', data: { storeName: input.storeName, retention } };
  // JSON in a script: «<» escaped so no store word can close the tag.
  const json = JSON.stringify(config).replace(/</g, '\\u003c');
  return `<!doctype html><html lang="es"><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
<style>:root{${tokens.join(';')}}body{margin:0;min-height:100vh;background:var(--store-background,#fff)}</style></head>
<body><main><h1>${input.storeName.replace(/[<&]/g, '')}</h1></main><script>${input.hosted ? 'window.PAGOSYA_HOSTED=true;' : ''}window.PAGOSYA_CONFIG=${json};</script></body></html>`;
}

/** Runs in the page: boxes, visibility, contrast of the title and the email label against their nearest opaque background. */
function measureInPage(): Omit<PopupMeasure, 'width' | 'height'> {
  const box = (el: Element | null | undefined): PopupBox | null => {
    if (!el) return null;
    const r = el.getBoundingClientRect();
    let visible = r.width > 0 && r.height > 0;
    for (let node: Element | null = el; node && visible; node = node.parentElement) {
      const style = getComputedStyle(node);
      if (style.display === 'none' || style.visibility === 'hidden' || Number(style.opacity) === 0) visible = false;
    }
    return { x: r.x, y: r.y, width: r.width, height: r.height, visible };
  };
  const rgb = (value: string) => { const n = (value.match(/[\d.]+/g) ?? ['0', '0', '0', '0']).map(Number); return { r: n[0], g: n[1], b: n[2], a: n.length > 3 ? n[3] : 1 }; };
  const lum = (c: { r: number; g: number; b: number }) => [c.r, c.g, c.b].map(v => v / 255).map(v => (v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4))
    .reduce((sum, v, i) => sum + v * [0.2126, 0.7152, 0.0722][i], 0);
  // The first ancestor painting a flat opaque colour; an image or gradient first means the text sits on a picture (null colour).
  const backdrop = (el: Element) => {
    for (let node: Element | null = el; node; node = node.parentElement) {
      const style = getComputedStyle(node);
      if (style.backgroundImage !== 'none') return { color: null, at: node };
      const colour = rgb(style.backgroundColor);
      if (colour.a >= 0.99) return { color: colour, at: node };
    }
    return { color: { r: 255, g: 255, b: 255, a: 1 }, at: null as Element | null };
  };
  const contrast = (el: Element | null | undefined) => {
    if (!el) return null;
    const bg = backdrop(el).color;
    if (!bg) return null;
    const [a, b] = [lum(rgb(getComputedStyle(el).color)) + 0.05, lum(bg) + 0.05];
    return Math.max(a, b) / Math.min(a, b);
  };
  const dialog = document.querySelector('dialog.pagosya-signup-dialog') as HTMLDialogElement | null;
  const photo = dialog?.querySelector('pya-photo img, .pagosya-signup-photo img') ?? null;
  const title = dialog?.querySelector('h2') ?? null;
  const email = dialog?.querySelector('input[type=email]') ?? null;
  const t = title?.getBoundingClientRect(), p = photo?.getBoundingClientRect();
  const overlaps = Boolean(t && p && t.left < p.right && t.right > p.left && t.top < p.bottom && t.bottom > p.top);
  const behindTitle = title ? backdrop(title).at : null;
  return {
    dialogOpen: Boolean(dialog?.open), scrollWidth: document.documentElement.scrollWidth,
    boxes: { dialog: box(dialog), close: box(dialog?.querySelector('.signup-close')), photo: box(photo), title: box(title), email: box(email),
      consent: box(dialog?.querySelector('.signup-consent')), submit: box(dialog?.querySelector('.signup-submit')) },
    contrast: { title: contrast(title), emailLabel: contrast(email?.closest('label')) },
    titleOverPhoto: overlaps && (!behindTitle || Boolean(photo && behindTitle.contains(photo))),
  };
}

export async function measurePopup(input: PopupRenderInput, sizes: ReadonlyArray<{ width: number; height: number }> = POPUP_SIZES): Promise<PopupMeasure[] | null> {
  let browser: Awaited<ReturnType<typeof chromium.launch>> | undefined;
  try {
    browser = await chromium.launch({ headless: true, chromiumSandbox: true, timeout: 10_000 });
  } catch { return null; }
  try {
    const script = readKitFileSync('retention.js');
    const measures: PopupMeasure[] = [];
    for (const size of sizes) {
      const context = await browser.newContext({ viewport: size, reducedMotion: 'reduce', serviceWorkers: 'block', acceptDownloads: false, offline: true, locale: 'es-ES' });
      await context.route('**/*', route => (route.request().url() === POPUP_PHOTO_URL && input.photo
        ? route.fulfill({ body: input.photo.bytes, contentType: input.photo.contentType })
        : route.abort()));
      const page = await context.newPage();
      await page.setContent(pageHtml(input), { waitUntil: 'domcontentloaded', timeout: 10_000 });
      await page.addScriptTag({ content: script });
      await page.waitForFunction(() => Boolean(document.querySelector('dialog[open]')), null, { timeout: 5_000 }).catch(() => undefined);
      await page.waitForFunction(() => { const img = document.querySelector('dialog[open] img') as HTMLImageElement | null; return !img || img.complete; }, null, { timeout: 3_000 }).catch(() => undefined);
      measures.push({ ...size, ...(await page.evaluate(measureInPage)) });
      await context.close();
    }
    return measures;
  } finally { await browser.close().catch(() => undefined); }
}

/** A store's own signup popup (spec 2026-11-08 AI popups), kept in StoreRetention.settings. */
export type PopupKit = { html: string; css: string; photo: string; seed: number; createdAt: string; model: string };
export type PopupKitSettings = { popupKit?: PopupKit; popupKitPrevious?: PopupKit; popupKitTriedAt?: string };

import { parseFragment, serialize } from 'parse5';
import postcss, { type AtRule, type Rule } from 'postcss';
import { isElement, kids, walk, type Element, type Node } from '../store-emails/email-dom';
import { POPUP_CSS_MAX_BYTES, POPUP_HTML_MAX_BYTES, POPUP_LOOSE_WORDS_MAX, POPUP_SLOTS, REQUIRED_POPUP_SLOTS } from './popup-kit-contract';

const LAYOUT_TAGS = new Set(['div', 'section', 'header', 'footer', 'figure', 'figcaption', 'span', 'p', 'strong', 'em', 'small', 'br', 'hr', 'ul', 'li']);
const SVG_TAGS = new Set(['svg', 'path', 'circle', 'rect', 'g']);
const SLOT_TAGS = new Set(POPUP_SLOTS.map(slot => `pya-${slot}`));
const SVG_ATTRS = new Set(['viewbox', 'd', 'fill', 'stroke', 'stroke-width', 'cx', 'cy', 'r', 'x', 'y', 'width', 'height', 'rx', 'transform']);
const URL_TEXT = /https?:|www\.|\.(?:com|bo|net|org)\b/i;
const OFFER = /\b(?:descuento|gratis|oferta|regalo|promo\w*|env[ií]o|rebaja|2x1)\b/i;
const NUMBER = /\d|%/;
// What a popup's CSS may never reach: the page, the dialog shell, the close button or the platform's own classes.
const BANNED_SELECTOR = /(?:^|[\s>+~(,])(?:html|body|dialog)(?![\w-])|:root|::backdrop|\.signup-close|\.pagosya-signup-(?:dialog|host)|&/i;
const HIDING = (prop: string, value: string) => (prop === 'display' && value === 'none') || (prop === 'visibility' && value === 'hidden') || (prop === 'opacity' && Number(value) === 0);

function checkHtml(html: string, problems: string[]): string | null {
  if (Buffer.byteLength(html) > POPUP_HTML_MAX_BYTES) { problems.push('html is over 12 KB'); return null; }
  const fragment = parseFragment(html);
  const counts = new Map<string, number>();
  for (const el of walk(fragment as unknown as Node) as Iterable<Element>) {
    const tag = el.tagName.toLowerCase();
    if (SLOT_TAGS.has(tag)) {
      counts.set(tag, (counts.get(tag) ?? 0) + 1);
      if (kids(el).length) problems.push(`${tag} must be empty`);
    } else if (!LAYOUT_TAGS.has(tag) && !SVG_TAGS.has(tag)) { problems.push(`<${tag}> not allowed`); continue; }
    for (const { name, value } of el.attrs) {
      const key = name.toLowerCase();
      const ok = key === 'class' ? /^[\w -]{1,120}$/.test(value)
        : key === 'aria-hidden' ? value === 'true' || value === 'false'
        : key === 'role' ? value === 'presentation'
        : SVG_TAGS.has(tag) && SVG_ATTRS.has(key) && !URL_TEXT.test(value) && !/url\(/i.test(value);
      if (!ok) problems.push(`attribute ${key} not allowed on ${tag}`);
    }
  }
  for (const slot of REQUIRED_POPUP_SLOTS) {
    const found = counts.get(`pya-${slot}`) ?? 0;
    if (found !== 1) problems.push(`pya-${slot} must appear exactly once (found ${found})`);
  }
  const codes = counts.get('pya-code') ?? 0;
  if (codes > 1) problems.push(`pya-code must appear at most once (found ${codes})`);
  // The kit's own words (slots are empty, so every text node is the model's).
  const loose: string[] = [];
  const collect = (node: Node) => { for (const child of kids(node)) { if (isElement(child)) collect(child); else if ('value' in child) loose.push(String((child as { value: string }).value)); } };
  collect(fragment as unknown as Node);
  const words = loose.join(' ').replace(/\s+/g, ' ').trim();
  if (words.length > POPUP_LOOSE_WORDS_MAX) problems.push(`words outside the slots are over ${POPUP_LOOSE_WORDS_MAX} characters`);
  if (URL_TEXT.test(words)) problems.push('a URL in the words outside the slots');
  if (OFFER.test(words)) problems.push('an offer in the words outside the slots (the platform says what the store offers)');
  if (NUMBER.test(words)) problems.push('a number in the words outside the slots (no prices, dates or percentages)');
  return serialize(fragment);
}

function checkCss(css: string, problems: string[]): string | null {
  if (Buffer.byteLength(css) > POPUP_CSS_MAX_BYTES) { problems.push('css is over 16 KB'); return null; }
  let root: postcss.Root;
  try { root = postcss.parse(css); } catch { problems.push('css cannot be parsed'); return null; }
  root.walkComments(comment => { comment.remove(); });
  root.walkAtRules(at => {
    const name = at.name.toLowerCase();
    if (!['media', 'keyframes', 'supports'].includes(name)) problems.push(`@${name} not allowed`);
    if (name === 'keyframes' && !/^pk-[\w-]{1,40}$/.test(at.params.trim())) problems.push(`keyframes «${at.params}» must be named pk-…`);
  });
  const inKeyframes = (node: postcss.Node) => { for (let p = node.parent; p; p = p.parent) if (p.type === 'atrule' && /keyframes$/i.test((p as AtRule).name)) return true; return false; };
  root.walkRules((rule: Rule) => {
    if (inKeyframes(rule)) return;
    rule.selectors = rule.selectors.map(raw => {
      const selector = raw.trim();
      if (BANNED_SELECTOR.test(selector)) problems.push(`selector «${selector}» not allowed`);
      return selector.startsWith('[data-popup-kit]') ? selector : `[data-popup-kit] ${selector}`;
    });
  });
  root.walkDecls(decl => {
    const prop = decl.prop.toLowerCase(), value = decl.value.toLowerCase().trim();
    if (prop === 'position' && /fixed|sticky/.test(value)) problems.push(`position:${value} not allowed`);
    if (/url\(/.test(value)) problems.push('url( not allowed (the photo comes from its slot)');
    if (/expression\(|javascript:/.test(value)) problems.push('expression( not allowed');
    if (prop === 'behavior' || prop === '-moz-binding') problems.push(`${prop} not allowed`);
    if (prop === 'content' && value.length > 22) problems.push('content over 20 characters');
    if (prop === 'z-index' && Number(value) > 10) problems.push('z-index above 10');
    const rule = decl.parent as Rule | undefined;
    if (!inKeyframes(decl) && rule?.type === 'rule' && /pya-/.test(rule.selector) && HIDING(prop, value)) problems.push(`«${rule.selector}» hides a slot`);
  });
  return root.toString();
}

/** A popup kit, cleaned and scoped; any problem refuses it whole (the problems go to the one repair call). */
export function validatePopupKit(raw: { html: string; css: string }): { ok: true; html: string; css: string } | { ok: false; problems: string[] } {
  const problems: string[] = [];
  const html = typeof raw.html === 'string' ? checkHtml(raw.html, problems) : (problems.push('html missing'), null);
  const css = typeof raw.css === 'string' ? checkCss(raw.css, problems) : (problems.push('css missing'), null);
  if (problems.length || html === null || css === null) return { ok: false, problems: [...new Set(problems)] };
  return { ok: true, html, css };
}

const PART_NAMES: Record<PopupPart, string> = { dialog: 'popup', close: 'close button', photo: 'photo', title: 'title', email: 'email field', consent: 'consent line', submit: 'button' };

/** The spec's render rules; each problem names the width, so the repair call knows where to look. */
export function checkPopupRender(measures: PopupMeasure[]): string[] {
  const problems: string[] = [];
  for (const m of measures) {
    const at = `at ${m.width}px`;
    if (!m.dialogOpen) { problems.push(`${at} the popup did not open`); continue; }
    const inside = (b: PopupBox, vertical: boolean) => b.x >= -1 && b.x + b.width <= m.width + 1 && (!vertical || (b.y >= -1 && b.y + b.height <= m.height + 1));
    for (const part of ['close', 'title', 'email', 'consent', 'submit'] as const) {
      const b = m.boxes[part];
      // A published store's email is typed in the secure form, so a missing email field is not a fault there.
      if (!b) { if (part !== 'email') problems.push(`${at} the ${PART_NAMES[part]} is hidden`); continue; }
      if (!b.visible) problems.push(`${at} the ${PART_NAMES[part]} is hidden`);
      else if (!inside(b, part === 'close' || part === 'title' || part === 'email')) problems.push(`${at} the ${PART_NAMES[part]} is outside the screen`);
    }
    const photo = m.boxes.photo;
    if (!photo || !photo.visible || photo.height < 120) problems.push(`${at} the photo is missing or under 120px tall`);
    if (m.contrast.title === null) problems.push(`${at} the title has no flat background colour`);
    else if (m.contrast.title < 4.5) problems.push(`${at} the title contrast is under 4.5:1`);
    if (m.contrast.emailLabel !== null && m.contrast.emailLabel < 4.5) problems.push(`${at} the email label contrast is under 4.5:1`);
    if (m.titleOverPhoto) problems.push(`${at} the title sits on the photo without a panel`);
    if (m.scrollWidth > m.width + 1) problems.push(`${at} the page scrolls sideways`);
  }
  return problems;
}

  provider: { endpoint: string; apiKey: string }; budget: SourceRequestBudget; fetchImpl?: typeof fetch;
  record?: (body: unknown, durationMs: number, status: 'COMPLETED' | 'FAILED') => Promise<unknown>;
}): Promise<{ raw: RawPopupKit; usage: unknown }> {
  const prompt = popupKitPrompt(input);
  const reservation = deps.budget.reserve(POPUP_KIT_MODEL, Math.ceil(prompt.length / 3), OUTPUT_TOKENS, 4_000);
  let body: any; let status: 'COMPLETED' | 'FAILED' = 'FAILED'; const started = Date.now();
  try {
    const response = await (deps.fetchImpl ?? fetch)(deps.provider.endpoint, {
      method: 'POST', signal: AbortSignal.timeout(120_000),
      headers: { Authorization: `Bearer ${deps.provider.apiKey}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({ model: POPUP_KIT_MODEL, store: false, instructions: 'Diseña la ventana de suscripción de la tienda como JSON estricto según el esquema.',
        input: [{ role: 'user', content: [{ type: 'input_text', text: prompt }] }], max_output_tokens: reservation.outputTokens,
        reasoning: { effort: 'medium' }, text: { format: { type: 'json_schema', name: 'popup_kit', strict: true, schema: SCHEMA } } }),
    });
    body = await response.json().catch(() => ({}));
    if (!response.ok) throw new BadGatewayException(FAILED);
    let parsed: any;
    try { parsed = sourceResponseJson(body); } catch { throw new BadGatewayException(FAILED); }
    if (!parsed || typeof parsed.html !== 'string' || typeof parsed.css !== 'string' || typeof parsed.photo !== 'string') throw new BadGatewayException(FAILED);
    status = 'COMPLETED';
    return { raw: { html: parsed.html, css: parsed.css, photo: parsed.photo }, usage: body?.usage };
  } finally {
    reservation.settle(body?.usage);
    await deps.record?.(body, Date.now() - started, status);
  }
}

/** The photos a popup may use: a chosen one first, the banner, the store's uploads, then product photos; upload paths only, ≤ 12. */
export function popupPhotos(sources: { banner?: string | null; uploads: string[]; products: Array<{ name: string; imageUrls: string[] }>; chosen?: string }): PopupPhoto[] {
  const photos: PopupPhoto[] = [];
  const add = (url: string | null | undefined, role: PopupPhoto['role'], label?: string) => {
    const path = url ? uploadOnly(url) : undefined;
    if (path && photos.length < 12 && !photos.some(photo => photo.url === path)) photos.push({ ref: `f${photos.length}`, role, url: path, ...(label ? { label } : {}) });
  };
  add(sources.chosen, 'tienda');
  add(sources.banner, 'portada');
  for (const url of sources.uploads) add(url, 'tienda');
  for (const product of sources.products) for (const url of product.imageUrls.slice(0, 2)) add(url, 'producto', product.name);
  return photos;
}

      if (settings.popupKit || settings.popupKitTriedAt || !store || Date.now() - new Date(store.createdAt).getTime() > NEW_STORE_MS) return;
      await this.write(storeId, current => ({ ...current, popupKitTriedAt: new Date().toISOString() }));
      const result = await this.design(storeId);
      if (result.status === 'saved') await this.say(storeId, POPUP_SAVED);
    } catch (error) {
      this.logger.warn(`popup design after build skipped for ${storeId}: ${String((error as Error)?.message ?? error).slice(0, 200)}`);
    }
  }

  /** «rediseña la ventana»: runs after the chat answered; the result is posted in the chat. */
  redesignInBackground(storeId: string, photo?: string): void {
    void this.design(storeId, photo ? { photo } : {})
      .then(result => this.say(storeId, result.status === 'saved' ? POPUP_REDESIGNED : POPUP_FAILED))
      .catch(error => { this.logger.warn(`popup redesign failed for ${storeId}: ${String((error as Error)?.message ?? error).slice(0, 200)}`); return this.say(storeId, POPUP_FAILED).catch(() => undefined); });
  }

  /** «cambia la foto de la ventana»: the design stays, its photo changes; false when the store has no design yet. */
  setPhoto(storeId: string, photo: string): Promise<boolean> {
    return this.write(storeId, current => (current.popupKit ? { ...current, popupKit: { ...current.popupKit, photo } } : null));
  }

  /** «vuelve a la ventana anterior»: one step, swapped (so asking again comes back). */
  undo(storeId: string): Promise<boolean> {
    return this.write(storeId, current => (current.popupKit && current.popupKitPrevious ? { ...current, popupKit: current.popupKitPrevious, popupKitPrevious: current.popupKit } : null));
  }
}

```ts
// Designs the signup popup of the stores named (spec 2026-11-08 AI popups). Runs only when the owner names the stores.
// Usage: cd apps/api && npx ts-node --transpile-only scripts/design-popups.ts <storeId…>
// Billed like any YAPI design (at most POPUP_KIT_MAX_CREDITS per store; free on the ChatGPT plan). Keeps the old design for undo.
import { NestFactory } from '@nestjs/core';
import { AppModule } from '../src/app.module';
import { PopupKitService } from '../src/store-popups/popup-kit.service';

async function main() {
  const ids = process.argv.slice(2).filter(id => /^[\w-]{6,40}$/.test(id));
  if (!ids.length) { console.error('Usage: npx ts-node --transpile-only scripts/design-popups.ts <storeId…>'); process.exit(1); }
  const app = await NestFactory.createApplicationContext(AppModule, { logger: ['error', 'warn'] });
  const kits = app.get(PopupKitService);
  for (const id of ids) {
    const result = await kits.design(id).catch(error => ({ status: 'error', problems: [String((error as Error)?.message ?? error)] }));
    console.log(`${id}\t${result.status}\t${result.problems.join(' | ')}`);
  }
  await app.close();
}
void main();
```
